= Configure o storage no host em E-Series para VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar o storage atribuído a um host ESXi como um datastore do Virtual Machine File System (VMFS) ou como um raw device mapping (RDM). Os RDMs não são suportados nos protocolos NVMe over fabric (NVMe over FC, NVMe over RoCE, NVMe over TCP).

Todas as versões atuais do ESXi são compatíveis com as versões 5 e 6 do VMFS.


NOTE: O uso de extensões VMFS no VMware não é recomendado. Em vez de adicionar outro volume como uma extensão a um datastore VMFS existente para aumentar a capacidade, recomenda-se executar uma operação DVE (https://kb.netapp.com/on-prem/E-Series/Management-Apps-KBs/How_to_expand_Volumes["Como expandir volumes - NetApp Knowledge Base"^] no volume de suporte existente e expandir o datastore VMFS.


NOTE: Recomenda-se o uso de RDMs virtuais ou discos virtuais em vez de RDMs físicos em máquinas virtuais Linux.

.Passos
. Certifique-se de que os volumes mapeados para o host ESXi foram descobertos corretamente.
. Para obter instruções sobre como criar datastores VMFS, consulte  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/working-with-datastores-in-vsphere-storage-environment/vsphere-vmfs-datastore-concepts-and-operations/create-a-vsphere-vmfs-datastore.html["Crie um datastore VMFS do vSphere"^].
. Para obter instruções sobre como criar RDMs, consulte  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/raw-device-mapping-in-vsphere.html["Mapeamento de Dispositivos Brutos em vSphere"^].
