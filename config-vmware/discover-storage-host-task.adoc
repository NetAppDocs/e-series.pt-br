= Descubra o storage no host na E-Series para VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Atribua os volumes ao host. Execute uma nova verificação para que o host detecte e configure os volumes para multipath.

Para obter informações sobre como criar hosts e atribuir volumes, consulte:

* https://docs.netapp.com/us-en/e-series-santricity/sm-storage/create-host-manually.html["Criar definições de host"^]
* https://docs.netapp.com/us-en/e-series-santricity/sm-storage/create-host-cluster.html["Criar cluster de hosts"^]
* https://docs.netapp.com/us-en/e-series-santricity/sm-storage/assign-volumes.html["Atribuir volumes aos hosts"^]


Por padrão, um host ESXi executa automaticamente uma nova varredura a cada cinco minutos. Um volume pode aparecer entre o momento em que você o cria e o atribui a um host, antes de executar uma nova digitalização manual. Independentemente disso, você pode executar uma nova verificação manual para garantir que todos os volumes estejam configurados corretamente.

.Passos
. Certifique-se de que os volumes sejam criados e atribuídos ao host ESXi conforme descrito nos links acima.
. Se estiver usando um vCenter Server, adicione o host ao inventário do servidor.
. Use o vSphere Client ou o vSphere Web Client para se conetar diretamente ao vCenter Server ou ao host ESXi.
. Para obter instruções sobre como executar uma nova verificação do storage em um host ESXi, consulte  https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/9-1/vsphere-storage/managing-esxi-storage-devices/rescan-operations-for-esxi-storage/perform-storage-rescan.html["Executar nova verificação de storage"^].
