= Guia rápido para configuração de host VMware no storage E-Series
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O método VMware Express para instalar seu array de storage e acessar o SANtricity System Manager é adequado para configurar um host VMware independente com um sistema de storage E-Series. Ele foi projetado para colocar o sistema de storage em funcionamento o mais rápido possível, com o mínimo de etapas de tomada de decisão.



[[procedure-overview]]
== Descrição geral do procedimento

O método expresso inclui as seguintes etapas, que também são descritas no link:understand-vmware-workflow-concept.html["Fluxo de trabalho da VMware"].

. Configure um dos seguintes ambientes de comunicação:
+
** link:nvme-fc-perform-specific-task.html["NVMe em Fibre Channel"]
** link:fc-perform-specific-task.html["Fibre Channel (FCP)"]
** link:iscsi-perform-specific-task.html["ISCSI"]
** link:sas-perform-specific-task.html["SAS"]
** link:nvme-roce-perform-specific-task.html["NVMe em RoCE"]
** link:nvme-tcp-perform-specific-task.html["NVMe sobre TCP"]


. Crie volumes lógicos no storage array.
. Disponibilize os volumes para o host de dados.
