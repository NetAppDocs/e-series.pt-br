= Saiba mais sobre a manutenção dos módulos de E/S para os sistemas de storage EF50 e EF80
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os sistemas de storage EF50 e EF80 oferecem flexibilidade na substituição ou atualização de módulos de E/S para melhorar a conectividade e o desempenho da rede, além de aumentar a capacidade de storage.

* link:io-module-replace.html["Substituir um módulo de E/S"]
+
Quando um módulo de E/S em seu sistema de storage falha, você pode substituí-lo por um módulo de E/S do mesmo tipo para restaurar o sistema de storage ao seu estado operacional ideal.

* link:io-module-upgrade.html["Atualizar um módulo de E/S"]
+
Você pode atualizar os módulos de E/S em seu sistema de storage para aumentar o número de portas de host para melhorar a conectividade de rede, expandir a capacidade do seu sistema de lidar com o tráfego de dados e conectar gabinetes de expansão SAS.

+

NOTE: Os módulos de E/S de expansão SAS são suportados em sistemas de storage que executam SANtricity 12.10 ou posterior.
